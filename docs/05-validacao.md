# Testes do projeto

Ainda não executamos os testes abaixo. Vamos preencher os resultados conforme o desenvolvimento avançar.

| Teste | O que vamos conferir | Situação |
| --- | --- | --- |
| Botões | Se o Arduino identifica os dois botões corretamente. | Não executado |
| Movimento | Se o personagem anda para o lado certo e para ao soltar. | Não executado |
| Botão segurado | Se manter apertado não gera vários acionamentos na contagem. | Não executado |
| Dois botões juntos | Se o comportamento definido funciona sem travar. | Não executado |
| Bordas | Se o personagem fica dentro da tela. | Não executado |
| Coleta | Se cada fruta coletada conta uma vez. | Não executado |
| Perdas | Se cada fruta perdida conta uma vez. | Não executado |
| Objeto a evitar | Se a colisão aplica a regra de pontuação definida. | Não executado |
| Menu | Se conseguimos iniciar, pausar e reiniciar pelo dispositivo. | Não executado |
| Pausa | Se o tempo e os objetos param durante a pausa. | Não executado |
| Reinício | Se a nova partida começa sem os dados da anterior. | Não executado |
| Fases | Se as três fases funcionam e têm dificuldade progressiva. | Não executado |
| Conexão | Se aparece um aviso quando o Arduino não está conectado ou é desconectado. | Não executado |
| Resultados | Se os valores mostrados batem com uma partida acompanhada pelo grupo. | Não executado |
| Sem dados | Se a taxa de coleta não dá erro quando nenhuma fruta foi avaliada. | Não executado |
| Executável | Se o jogo abre fora da IDE no computador usado na entrega. | Não executado |
